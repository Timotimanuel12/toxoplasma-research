# Toxoplasma Sem 5 Research

Predicting *Toxoplasma gondii* seropositivity with machine learning.

| Folder | Status | What it is |
|---|---|---|
| [`makassar_project/`](makassar_project/) | **Active** | Self-distillation study on public data from 184 pregnant women in Makassar, Indonesia (Polanunu et al., 2021, *PLoS ONE*). Start with [`MAKASSAR_PROJECT_SUMMARY.md`](makassar_project/MAKASSAR_PROJECT_SUMMARY.md). |
| [`nhanes_project/`](nhanes_project/) | Finished | Survey-based prediction on NHANES 2013–2014 (5,006 U.S. adults). Start with [`NHANES_PROJECT_SUMMARY.md`](nhanes_project/NHANES_PROJECT_SUMMARY.md). |

Each project has the same layout: `data/raw/`, `data/processed/`, `scripts/`, `outputs/`. Run scripts from inside the project folder.
